One codebase. Every platform. No compatibility hacks.

Cross-platform is a promise most security tools make and very few keep. ReconPro actually delivers. The entire codebase is pure Python — no C extensions, no compiled binaries, nothing that breaks when you switch operating systems. We ship a py3-none-any wheel, which is the most universal package format possible. Early on we hit a nasty bug where os.uname() crashed on Windows — we ripped it out and replaced it with a cross-platform abstraction. Same code, same commands, same output on Windows 10 and 11, Ubuntu, Debian, and macOS. Whether you're a red teamer on Kali or a defender on a corporate Windows laptop, the experience is identical. One codebase. Every platform. No hacks.
