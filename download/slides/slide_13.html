33 COMMANDS. INFINITE POWER.

reconpro — bash

Core

$ reconpro scan --target example.com

$ reconpro scan --modules gorgon,oblivion

$ reconpro report --format json

Modules

$ reconpro gorgon --target example.com

$ reconpro oblivion --url https://example.com

$ reconpro pegasus --full-scan

Team

$ reconpro team add @hacker --role lead

$ reconpro team list

Integrations

$ reconpro integrations slack --channel #alerts

Utilities

$ reconpro doctor --check-all

$ reconpro export --format pdf

Every command has --help. Every module can run standalone or combined.

This is the heart of ReconPro — the CLI. Thirty-three commands give you complete control over every module, every integration, and every workflow. The design philosophy is simple: if you can type it, ReconPro can do it. Core commands handle scanning and reporting. Module commands let you invoke GORGON, OBLIVION, or PEGASUS directly. Team commands manage your crew. Integration commands plug into Slack, Jira, Splunk, and more. And utility commands like doctor and export keep your environment healthy. Every single command supports --help, so you're never lost. And every module can run independently or chained together in a single scan. This isn't a GUI with a CLI bolted on — the CLI is the product.
