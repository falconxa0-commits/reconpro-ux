   373→   397→   397→## 4. Code Patterns That Need Hardening
   374→   398→   398→
   375→   399→   399→### Pattern 1: Unsanitized File Paths from URL Segments
   376→   400→   400→**Files:** `server.py:206, 289`  
   377→   401→   401→**Pattern:** `path.split("/<prefix>/")[1]` → direct use in `os.path.join()` / `Path() / filename`  
   378→   402→   402→**Risk:** Path traversal  
   379→   403→   403→**Fix:** Always resolve and validate against a trusted base directory.
   380→   404→   404→
   381→   405→   405→### Pattern 2: User Data in HTML Without Escaping
   382→   406→   406→**Files:** `reports.py:801-811`, `formats.py:382-387`  
   383→   407→   407→**Pattern:** `f'<td>{f.get("title", "")}</td>'`  
   384→   408→   408→**Risk:** XSS  
   385→   409→   409→**Fix:** `f'<td>{html.escape(f.get("title", ""))}</td>'`
   386→   410→   410→
   387→   411→   411→### Pattern 3: Exception Details in API Responses
   388→   412→   412→**Files:** `server.py:250, 264, 501`  
   389→   413→   413→**Pattern:** `self._json_response(500, {"error": str(e)})`  
   390→   414→   414→**Risk:** Information disclosure  
   391→   415→   415→**Fix:** Log `str(e)` server-side, return generic error to client.
   392→   416→   416→
   393→   417→   417→### Pattern 4: Missing Input Validation at Entry Points
   394→   418→   418→**Files:** `server.py:360` (audit), `scanner.py:155` (audit_scan)  
   395→   419→   419→**Pattern:** User `target` passed to modules without `validate_target()` or `security.sanitize_target()`  
   396→   420→   420→**Risk:** Injection into shell commands and file paths  
   397→   421→   421→**Fix:** Call `validate_target()` and `security.sanitize_target()` before processing.
   398→   422→   422→
   399→   423→   423→### Pattern 5: `shell=True` Subprocess Helper
   400→   424→   424→**Files:** `modules/host.py:48-56`  
   401→   425→   425→**Pattern:** `subprocess.run(cmd, shell=True, ...)`  
   402→   426→   426→**Risk:** Command injection if any caller passes unsanitized input  
   403→   427→   427→**Fix:** Refactor to use `subprocess.run([...], shell=False)`.
   404→   428→   428→
   405→   429→   429→### Pattern 6: Unrestricted Redirect Following
   406→   430→   430→**Files:** `async_http.py:451-495, 564-613`, `connection_pool.py:157-160`  
   407→   431→   431→**Pattern:** Follow redirects without scheme/IP validation  
   408→   432→   432→**Risk:** SSRF  
   409→   433→   433→**Fix:** Validate each redirect target against private IP ranges and scheme allowlist.
   410→   434→   434→
   411→   435→   435→### Pattern 7: Module-Level Mutable State
   412→   436→   436→**Files:** `server.py:57` (`_API_TOKENS`), `mitm.py:65-69` (`_captured`, `_api_endpoints`), `plugins.py:143-144` (`_HOOK_REGISTRY`)  
   413→   437→   437→**Pattern:** Shared mutable dicts/lists without consistent locking  
   414→   438→   438→**Risk:** Race conditions in threaded contexts  
   415→   439→   439→**Fix:** Use `threading.Lock` consistently around all reads and writes.
