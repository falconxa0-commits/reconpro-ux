   445→  1445→### Recipe R5: Clean White (Academic)
   446→  1446→
   447→  1447→**Visual:** Pure white background + school name + centered title + 2-column meta info table with underlines + footer
   448→  1448→**Use case:** academic thesis, standards documents
   449→  1449→**Architecture:** 16838 outer wrapper (white fill, invisible) + cell margins for page margin simulation. No top/bottom decorative lines.
   450→  1450→
   451→  1451→**Meta info table rules (cross-engine safe):**
   452→  1452→- 2-column table: label + value, **percentage widths only** (`WidthType.PERCENTAGE`)
   453→  1453→- **Table width is adaptive:** 55–75% of page, calculated by `calcR5MetaLayout()`. Table centered via `alignment: CENTER`.
   454→  1454→- **Label column:** adaptive 25–45% of table, **LEFT aligned**, plain text with "：" appended. NO full-width space padding, NO right-alignment.
   455→  1455→- **Label column borders:** none (no bottom border on label cells).
   456→  1456→- **Value column:** remaining %, **LEFT aligned**, `bottom: single sz=4` border = fixed-length underline (consistent length for all rows regardless of text).
   457→  1457→- No left/right/top borders on either column.
   458→  1458→- ⚠️ Do NOT use DXA widths, full-width space padding (`\u3000`), spacer columns, or tab stops — WPS renders them inconsistently.
   459→  1459→- ⚠️ Do NOT use `margins.top` on the wrapper cell — use `spacing.before` on first paragraph instead.
   460→  1460→
   461→  1461→**Known limitation:** When meta lines ≥ 6 AND title has 3 lines, MS Office may render content slightly taller than WPS, potentially clipping the footer line. Mitigate by reducing `midSpacing` or using a smaller title font.
   462→  1462→
   463→  1463→```js
   464→  1464→// ── Width-aware title layout (handles mixed Chinese + English) ──
   465→  1465→function estimateTextWidth(text, pt) {
   466→  1466→  let width = 0;
   467→  1467→  for (const ch of text) {
   468→  1468→    const code = ch.codePointAt(0);
   469→  1469→    const isCJK = (code >= 0x4E00 && code <= 0x9FFF) || (code >= 0x3400 && code <= 0x4DBF) ||
   470→  1470→      (code >= 0x3000 && code <= 0x303F) || (code >= 0xFF00 && code <= 0xFFEF) ||
   471→  1471→      (code >= 0x2E80 && code <= 0x2EFF);
   472→  1472→    width += isCJK ? pt * 20 : pt * 11; // CJK: full-width, Latin: ~55% width
   473→  1473→  }
   474→  1474→  return width;
   475→  1475→}
   476→  1476→// Use estimateTextWidth() in calcTitleLayout() instead of simple char count
   477→  1477→// to prevent mid-word breaks in mixed Chinese+English titles like "基于Transformer架构的..."
   478→  1478→
   479→  1479→// ── Meta info table ──
   480→  1480→
   481→  1481→// Calculate adaptive table and label column percentage based on longest label.
   482→  1482→// Returns { tablePct, labelPct } — both as percentages.
   483→  1483→// Uses ONLY WidthType.PERCENTAGE for cross-engine compatibility (MS Office + WPS).
   484→  1484→function calcR5MetaLayout(metaEntries, fontPt = 12) {
   485→  1485→  const maxLabelLen = Math.max(...metaEntries.map(e => [...e.label].length));
   486→  1486→  // Label needs: maxLabelLen chars + "：" + 1 char padding
   487→  1487→  const labelNeedTw = (maxLabelLen + 2) * fontPt * 20;
   488→  1488→  // Value column: fixed ~5000tw for consistent underline length
   489→  1489→  const valueNeedTw = 5000;
   490→  1490→  const totalNeedTw = labelNeedTw + valueNeedTw;
   491→  1491→  // Table width as % of page (11906tw), clamped to 55–75%
   492→  1492→  const tablePct = Math.min(75, Math.max(55, Math.ceil(totalNeedTw / 11906 * 100)));
   493→  1493→  // Label % within the table, clamped to 25–45%
   494→  1494→  const rawLabelPct = Math.ceil(labelNeedTw / (tablePct / 100 * 11906) * 100);
   495→  1495→  return { tablePct, labelPct: Math.max(25, Math.min(45, rawLabelPct)) };
   496→  1496→}
   497→  1497→
   498→  1498→// Build R5 academic cover meta info table.
   499→  1499→// ⚠️ CRITICAL cross-engine rules:
   500→  1500→//   - Table width: WidthType.PERCENTAGE (NOT DXA — WPS breaks with DXA)
   501→  1501→//   - Column widths: WidthType.PERCENTAGE
   502→  1502→//   - Label column: LEFT aligned, plain text (NO full-width space padding)
   503→  1503→//   - Value column: LEFT aligned, bottom border = fixed-length underline
   504→  1504→//   - Table alignment: CENTER (visually centered on page)
   505→  1505→function buildR5MetaTable(metaEntries) {
   506→  1506→  // metaEntries: [{ label: "学院", value: "计算机科学与技术学院" }, ...]
   507→  1507→  const { tablePct, labelPct } = calcR5MetaLayout(metaEntries);
   508→  1508→  const valuePct = 100 - labelPct;
   509→  1509→  const bottomBorder = { style: BorderStyle.SINGLE, size: 4, color: "000000" };
   510→  1510→
   511→  1511→  const rows = metaEntries.map(entry => new TableRow({
   512→  1512→    children: [
   513→  1513→      // Label cell: left-aligned, no bottom border
   514→  1514→      new TableCell({
   515→  1515→        width: { size: labelPct, type: WidthType.PERCENTAGE },
   516→  1516→        borders: noBorders,
   517→  1517→        margins: { top: 60, bottom: 60, left: 0, right: 0 },
   518→  1518→        children: [new Paragraph({
   519→  1519→          alignment: AlignmentType.LEFT,
   520→  1520→          spacing: { before: 60, after: 60, line: 400 },
   521→  1521→          children: [new TextRun({
   522→  1522→            text: entry.label + "：",
   523→  1523→            size: 24, font: { eastAsia: "SimSun", ascii: "Times New Roman" },
   524→  1524→          })],
   525→  1525→        })],
   526→  1526→      }),
   527→  1527→      // Value cell: left-aligned, bottom border = fixed-length underline
   528→  1528→      new TableCell({
   529→  1529→        width: { size: valuePct, type: WidthType.PERCENTAGE },
   530→  1530→        borders: { top: NB, left: NB, right: NB, bottom: bottomBorder },
   531→  1531→        margins: { top: 60, bottom: 60, left: 80, right: 0 },
   532→  1532→        children: [new Paragraph({
   533→  1533→          alignment: AlignmentType.LEFT,
   534→  1534→          spacing: { before: 60, after: 60, line: 400 },
   535→  1535→          children: [new TextRun({
   536→  1536→            text: entry.value,
   537→  1537→            size: 24, font: { eastAsia: "SimSun", ascii: "Times New Roman" },
   538→  1538→          })],
   539→  1539→        })],
   540→  1540→      }),
   541→  1541→    ],
   542→  1542→  }));
   543→  1543→
   544→  1544→  return new Table({
   545→  1545→    width: { size: tablePct, type: WidthType.PERCENTAGE },
   546→  1546→    alignment: AlignmentType.CENTER,
   547→  1547→    layout: TableLayoutType.FIXED,
   548→  1548→    borders: allNoBorders,
   549→  1549→    rows,
   550→  1550→  });
   551→  1551→}

   553→  1553→// ⚠️ MANDATORY: Cover section must use margin: 0. See "Cover Section Non-Negotiables" above.
   554→  1554→function buildCoverR5(config) {
   555→  1555→  const PAGE_H = 16838, SAFETY = 1200;
   556→  1556→  const safeH = PAGE_H - SAFETY; // 15638
   557→  1557→  const simMarginLR = 1701, simMarginT = 1200;
   558→  1558→  const contentW = 11906 - simMarginLR * 2;
   559→  1559→
   560→  1560→  // ★ Width-aware title layout for mixed Chinese+English
   561→  1561→  const { titlePt, titleLines } = calcTitleLayoutMixed(config.title, contentW, 36, 24);
   562→  1562→  const titleSize = titlePt * 2;
   563→  1563→
   564→  1564→  // Parse meta entries
   565→  1565→  const metaEntries = (config.metaLines || []).map(line => {
   566→  1566→    const sep = line.indexOf("：") !== -1 ? "：" : ":";
   567→  1567→    const idx = line.indexOf(sep);
   568→  1568→    if (idx === -1) return { label: line, value: "" };
   569→  1569→    return { label: line.slice(0, idx).trim(), value: line.slice(idx + sep.length).trim() };
   570→  1570→  });
   571→  1571→
   572→  1572→  // Height budget (no margins.top — use spacing.before instead)
   573→  1573→  const schoolNameH = config.schoolName ? (22 * 23 + 400) : 0;
   574→  1574→  const titleTotalH = titleLines.length * (titlePt * 23 + 200);
   575→  1575→  const subtitleH = config.subtitle ? (15 * 23 + 600) : 0;
   576→  1576→  const metaRowH = 520; // 60+60 padding + ~400 line height
   577→  1577→  const metaTableH = metaEntries.length * metaRowH;
   578→  1578→  const footerH = config.footerRight ? (12 * 23 + 200) : 0;
   579→  1579→  const spacerParas = 3 * 350;
   580→  1580→  const fixedH = schoolNameH + titleTotalH + subtitleH + metaTableH + footerH + spacerParas;
   581→  1581→  const remaining = Math.max(safeH - fixedH, 600);
   582→  1582→
   583→  1583→  // ★ topSpacing includes simulated top margin (simMarginT)
   584→  1584→  const topSpacing = Math.min(Math.floor(remaining * 0.28) + simMarginT, 4200);
   585→  1585→  const midSpacing = Math.min(Math.floor((remaining - simMarginT) * 0.18), 2000);
   586→  1586→  const bottomSpacing = Math.min(remaining - topSpacing + simMarginT - midSpacing, 5500);
   587→  1587→
   588→  1588→  const children = [];
   589→  1589→  children.push(new Paragraph({ spacing: { before: topSpacing } }));
   590→  1590→
   591→  1591→  // School name (optional)
   592→  1592→  if (config.schoolName) {
   593→  1593→    children.push(new Paragraph({
   594→  1594→      alignment: AlignmentType.CENTER, spacing: { after: 400 },
   595→  1595→      children: [new TextRun({ text: config.schoolName, size: 44, characterSpacing: 40,
   596→  1596→        font: { eastAsia: "SimSun", ascii: "Times New Roman" } })],
   597→  1597→    }));
   598→  1598→  }
   599→  1599→
   600→  1600→  // Title
   601→  1601→  for (let i = 0; i < titleLines.length; i++) {
   602→  1602→    children.push(new Paragraph({
   603→  1603→      alignment: AlignmentType.CENTER, spacing: { after: i < titleLines.length - 1 ? 120 : 300 },
   604→  1604→      children: [new TextRun({ text: titleLines[i], size: titleSize, bold: true,
   605→  1605→        font: { eastAsia: "SimHei", ascii: "Times New Roman" } })],
   606→  1606→    }));
   607→  1607→  }
   608→  1608→
   609→  1609→  // Subtitle
   610→  1610→  if (config.subtitle) {
   611→  1611→    children.push(new Paragraph({
   612→  1612→      alignment: AlignmentType.CENTER, spacing: { after: 200 },
   613→  1613→      children: [new TextRun({ text: config.subtitle, size: 30,
   614→  1614→        font: { eastAsia: "SimSun", ascii: "Times New Roman" } })],
   615→  1615→    }));
   616→  1616→  }
   617→  1617→
   618→  1618→  children.push(new Paragraph({ spacing: { before: midSpacing } }));
   619→  1619→
   620→  1620→  // Meta info table
   621→  1621→  if (metaEntries.length > 0) children.push(buildR5MetaTable(metaEntries));
   622→  1622→
   623→  1623→  children.push(new Paragraph({ spacing: { before: bottomSpacing } }));
   624→  1624→
   625→  1625→  // Footer
   626→  1626→  if (config.footerRight) {
   627→  1627→    children.push(new Paragraph({
   628→  1628→      alignment: AlignmentType.CENTER,
   629→  1629→      children: [new TextRun({ text: config.footerRight, size: 24, color: "404040",
   630→  1630→        font: { eastAsia: "SimSun", ascii: "Times New Roman" } })],
   631→  1631→    }));
   632→  1632→  }
   633→  1633→
   634→  1634→  // ★ 16838 outer wrapper — only left/right margins, NO margins.top
   635→  1635→  return [new Table({
   636→  1636→    width: { size: 100, type: WidthType.PERCENTAGE },
   637→  1637→    layout: TableLayoutType.FIXED,
   638→  1638→    borders: allNoBorders,
   639→  1639→    rows: [new TableRow({
   640→  1640→      height: { value: PAGE_H, rule: "exact" },
   641→  1641→      children: [new TableCell({
   642→  1642→        shading: { type: ShadingType.CLEAR, fill: "FFFFFF" },
   643→  1643→        borders: noBorders, verticalAlign: "top",
   644→  1644→        margins: { left: simMarginLR, right: simMarginLR },
   645→  1645→        children,
   646→  1646→      })],
   647→  1647→    })],
   648→  1648→  })];
   649→  1649→  // Height budget example (short title, 4 meta lines):
   650→  1650→  // topSpacing(3818) + schoolName(906) + title(1028) + subtitle(945) + midSpacing(1467)
   651→  1651→  // + metaTable(4×520=2080) + bottomSpacing(5268) + footer(476) = ~15988 < 15838 ✅
   652→  1652→}

   660→  1660→function blendColors(hex1, hex2, ratio) {
   661→  1661→  const p = (s, i) => parseInt(s.replace("#","").slice(i, i+2), 16);
   662→  1662→  const mix = (c1, c2) => Math.round(c1 + (c2 - c1) * ratio);
   663→  1663→  const r = mix(p(hex1,0), p(hex2,0)), g = mix(p(hex1,2), p(hex2,2)), b = mix(p(hex1,4), p(hex2,4));
   664→  1664→  return [r, g, b].map(v => v.toString(16).padStart(2,"0")).join("");
   665→  1665→}

   700→  1700→### Chart Color Palette
   701→  1701→
   702→  1702→Default: **low-saturation (Morandi style)** palette to avoid flashy high-saturation. High-saturation palette only for explicitly energetic scenarios (events/education/creative).
   703→  1703→
   704→  1704→```js

   706→  1706→  // Default: low saturation, professional (S: 25-40%, L: 55-68%)
   707→  1707→  default: ["6B9DAD", "C49B72", "7BA68A", "B87472", "9687A8", "C8B87C", "7AADA0", "7A9BB8"],
   708→  1708→  // Vivid: only for energetic/creative scenes
   709→  1709→  vivid:   ["2F97B8", "E67E22", "27AE60", "E74C3C", "9B59B6", "F1C40F", "1ABC9C", "3498DB"],
   710→  1710→};
   711→  1711→
   712→  1712→// Scene selection:
   713→  1713→// - report/whitepaper/consulting/academic/contract → default
   714→  1714→// - activity/education/creative copy → vivid (optional)
   715→  1715→```
   716→  1716→
   717→  1717→**Color usage rules:**
   718→  1718→- Max **5 colors** per chart; excess categories use depth variants of same hue
   719→  1719→- Emphasis data uses document accent color; non-emphasis uses grey `#B0B0B0`
   720→  1720→- Adjacent segments in pie/bar charts must have hue gap ≥ 60°
   721→  1721→
   722→  1722→1. **Anti-overlap**: If >6 x-axis labels, rotate 45° (`plt.xticks(rotation=45, ha='right')`)
   723→  1723→2. **Anti-stretch**: Always set figure size explicitly (`fig, ax = plt.subplots(figsize=(10, 6))`)
   724→  1724→3. **Aspect ratio (CRITICAL)**: When embedding in docx, MUST read actual image dimensions and calculate height proportionally. NEVER hardcode both width and height — pie charts become ellipses, radar charts become diamonds.
   725→  1725→   ```js
   726→  1726→   const sizeOf = require("image-size");
   727→  1727→   const dims = sizeOf(chartBuffer);
   728→  1728→   const displayWidth = 500;
   729→  1729→   const displayHeight = Math.round(displayWidth * (dims.height / dims.width));
   730→  1730→   // transformation: { width: displayWidth, height: displayHeight }
   731→  1731→   ```
   732→  1732→4. **DPI**: Save at 200+ DPI (`plt.savefig("chart.png", dpi=200, bbox_inches="tight")`)
   733→  1733→5. **Colors**: Use palette accent color for primary data series
   734→  1734→6. **Legend**: Place outside plot area if >4 series
   735→  1735→7. **Square charts**: Pie and radar charts MUST use `figsize=(8, 8)` (equal width/height) to preserve circular/radial shape
   736→  1736→7. **Grid**: Light gray grid (`ax.grid(True, alpha=0.3)`)
