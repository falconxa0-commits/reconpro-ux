   116→   116→   516→   516→   516→### Page Breaks
   117→   117→   517→   517→   517→
   118→   118→   518→   518→   518→Follow the document type strategy defined in SOUL.md Rule 1.
   119→   119→   519→   519→   519→
   120→   120→   520→   520→   520→**Structural breaks (always - MANDATORY):**
   121→   121→   521→   521→   521→- Between cover page and TOC - **cover must NEVER share a page with anything else**
   122→   122→   522→   522→   522→- Between TOC and main content
   123→   123→   523→   523→   523→- Between main content and back cover
   124→   124→   524→   524→   524→
   125→   125→   525→   525→   525→**Content breaks (by document type):**
   126→   126→   526→   526→   526→- **Default (all document types)**: ❗ **Absolutely NEVER force page breaks before H1/H2** — content flows naturally, do not insert `PageBreak()` before section headings. This is an iron rule.
   127→   127→   527→   527→   527→- Resume / contract / letter → No content page breaks
   128→   128→   528→   528→   528→- Short article → No content page breaks
   129→   129→   529→   529→   529→- **Exception 1**: Academic papers / textbooks / teaching plans → `PageBreak()` before each H1 is acceptable (only if user explicitly requests academic formatting)
   130→   130→   530→   530→   530→- **Exception 2**: User explicitly requests page breaks between chapters
   131→   131→   531→   531→   531→
   132→   132→   532→   532→   532→**Anti-tear (mandatory — but with height limit):**
   133→   133→   533→   533→   533→```python
   134→   134→   534→   534→   534→from reportlab.platypus import KeepTogether
   135→   135→   535→   535→   535→from reportlab.lib.pagesizes import A4
   136→   136→   536→   536→   536→from reportlab.lib.units import inch
   137→   137→   537→   537→   537→
   138→   138→   538→   538→   538→# Maximum height for KeepTogether blocks: 40% of page height
   139→   139→   539→   539→   539→# Blocks taller than this should NOT be kept together — they cause
   140→   140→   540→   540→   540→# the preceding page to be mostly empty when the block gets pushed down.
   141→   141→   541→   541→   541→MAX_KEEP_HEIGHT = A4[1] * 0.4  # ~336pt ≈ 12cm
   142→   142→   542→   542→   542→
   143→   143→   543→   543→   543→def safe_keep_together(elements):
   144→   144→   544→   544→   544→    """Wrap elements in KeepTogether only if their total height is reasonable.
   145→   145→   545→   545→   545→    If too tall, keep only the FIRST TWO elements together (e.g. title + table/image header)
   146→   146→   546→   546→   546→    to prevent title-content separation, while letting the rest paginate naturally.
   147→   147→   547→   547→   547→    """
   148→   148→   548→   548→   548→    total_h = 0
   149→   149→   549→   549→   549→    for el in elements:
   150→   150→   550→   550→   550→        w, h = el.wrap(A4[0] - 2*inch, A4[1])
   151→   151→   551→   551→   551→        total_h += h
   152→   152→   552→   552→   552→    if total_h <= MAX_KEEP_HEIGHT:
   153→   153→   553→   553→   553→        return [KeepTogether(elements)]
   154→   154→   554→   554→   554→    elif len(elements) >= 2:
   155→   155→   555→   555→   555→        # Keep at least title + first element together to prevent title orphaning
   156→   156→   556→   556→   556→        return [KeepTogether(elements[:2])] + list(elements[2:])
   157→   157→   557→   557→   557→    else:
   158→   158→   558→   558→   558→        return list(elements)
   159→   159→   559→   559→   559→
   160→   160→   560→   560→   560→# Heading stays with first paragraph
   161→   161→   561→   561→   561→story.extend(safe_keep_together([
   162→   162→   562→   562→   562→    heading_paragraph,
   163→   163→   563→   563→   563→    first_body_paragraph,
   164→   164→   564→   564→   564→]))
   165→   165→   565→   565→   565→
   166→   166→   566→   566→   566→# Image + caption: keep together ONLY if image is small
   167→   167→   567→   567→   567→story.extend(safe_keep_together([image, caption_paragraph]))
   168→   168→   568→   568→   568→
   169→   169→   569→   569→   569→# Table title + table: keep together ONLY if table is short
   170→   170→   570→   570→   570→if len(table_data) <= 15:
   171→   171→   571→   571→   571→    story.extend(safe_keep_together([table_title, table]))
   172→   172→   572→   572→   572→else:
   173→   173→   573→   573→   573→    # Long table: just keep title with the table start
   174→   174→   574→   574→   574→    story.extend(safe_keep_together([table_title]))
   175→   175→   575→   575→   575→    story.append(table)
   176→   176→   576→   576→   576→```
   177→   177→   577→   577→   577→
   178→   178→   578→   578→   578→**⚠️ KEY INSIGHT:** `KeepTogether` is the #1 cause of “empty page with chart on next page”.
   179→   179→   579→   579→   579→When a `KeepTogether` block is taller than the remaining space on the current page,
   180→   180→   580→   580→   580→ReportLab pushes the **entire block** to the next page, leaving the current page mostly empty.
   181→   181→   581→   581→   581→**Always use `safe_keep_together()` to cap the maximum block height.**
   182→   182→   582→   582→   582→
   183→   183→   583→   583→   583→**⚠️ Note:** Do NOT use `KeepWithNext` - it is unreliable in ReportLab 4.x.

   195→   195→   595→   595→   595→### Cover Page: HTML/Playwright Unified Cover System
   196→   196→   596→   596→   596→
   197→   197→   597→   597→   597→**⚠️ Report route covers are ALWAYS generated via HTML/Playwright**, using the same 5-template system defined in `typesetting/cover.md`.    198→   198→   598→   598→   598→
   199→   199→   599→   599→   599→**Pipeline (Report route):**
   200→   200→   600→   600→   600→1. Generate **body PDF** via ReportLab (start with TOC or content - **no cover in story[]**)

   205→   205→   605→   605→   605→   node "$PDF_SKILL_DIR/scripts/cover_validate.js" cover.html
   206→   206→   606→   606→   606→   ```

   208→   208→   608→   608→   608→6. **Merge: insert cover as page 0** of body PDF using pypdf → output single final PDF

HTML/CSS handles these natively. One cover system, one visual standard, zero inconsistency.

   270→   270→   670→   670→   670→
   271→   271→   671→   671→   671→def render_cover(html_path, pdf_path):
   272→   272→   672→   672→   672→    """Render HTML cover to PDF via html2poster.js.
   273→   273→   673→   673→   673→    
   274→   274→   674→   674→   674→    ⚠️ ALWAYS use html2poster.js for covers (NOT html2pdf-next.js).
   275→   275→   675→   675→   675→    Cover HTML uses position:absolute for layout. html2pdf-next.js pre-render

   289→   289→   689→   689→   689→from pypdf import PdfReader, PdfWriter
   290→   290→   690→   690→   690→
   291→   291→   691→   691→   691→A4_W, A4_H = 595.28, 841.89  # A4 in points
   292→   292→   692→   692→   692→
   293→   293→   693→   693→   693→def normalize_page_to_a4(page):
   294→   294→   694→   694→   694→    """Scale a page to A4 if its dimensions don't match."""
   295→   295→   695→   695→   695→    box = page.mediabox
   296→   296→   696→   696→   696→    w, h = float(box.width), float(box.height)
   297→   297→   697→   697→   697→    if abs(w - A4_W) > 2 or abs(h - A4_H) > 2:
   298→   298→   698→   698→   698→        page.scale_to(A4_W, A4_H)
   299→   299→   699→   699→   699→    return page

   301→   301→   701→   701→   701→def insert_cover(cover_pdf, body_pdf, output_pdf):
   302→   302→   702→   702→   702→    """Insert cover as first page of body PDF → single output file."""
   303→   303→   703→   703→   703→    writer = PdfWriter()

   308→   308→   708→   708→   708→    for page in PdfReader(body_pdf).pages:
   309→   309→   709→   709→   709→        writer.add_page(normalize_page_to_a4(page))

   311→   311→   711→   711→   711→    with open(output_pdf, 'wb') as f:
   312→   312→   712→   712→   712→        writer.write(f)
   313→   313→   713→   713→   713→```
