   115→   115→   132→   132→   532→   532→   532→**Anti-tear (mandatory — but with height limit):**
   116→   116→   133→   133→   533→   533→   533→```python
   117→   117→   134→   134→   534→   534→   534→from reportlab.platypus import KeepTogether
   118→   118→   135→   135→   535→   535→   535→from reportlab.lib.pagesizes import A4
   119→   119→   136→   136→   536→   536→   536→from reportlab.lib.units import inch
   120→   120→   137→   137→   537→   537→   537→
   121→   121→   138→   138→   538→   538→   538→# Maximum height for KeepTogether blocks: 40% of page height
   122→   122→   139→   139→   539→   539→   539→# Blocks taller than this should NOT be kept together — they cause
   123→   123→   140→   140→   540→   540→   540→# the preceding page to be mostly empty when the block gets pushed down.
   124→   124→   141→   141→   541→   541→   541→MAX_KEEP_HEIGHT = A4[1] * 0.4  # ~336pt ≈ 12cm
   125→   125→   142→   142→   542→   542→   542→
   126→   126→   143→   143→   543→   543→   543→def safe_keep_together(elements):
   127→   127→   144→   144→   544→   544→   544→    """Wrap elements in KeepTogether only if their total height is reasonable.
   128→   128→   145→   145→   545→   545→   545→    If too tall, keep only the FIRST TWO elements together (e.g. title + table/image header)
   129→   129→   146→   146→   546→   546→   546→    to prevent title-content separation, while letting the rest paginate naturally.
   130→   130→   147→   147→   547→   547→   547→    """
   131→   131→   148→   148→   548→   548→   548→    total_h = 0
   132→   132→   149→   149→   549→   549→   549→    for el in elements:
   133→   133→   150→   150→   550→   550→   550→        w, h = el.wrap(A4[0] - 2*inch, A4[1])
   134→   134→   151→   151→   551→   551→   551→        total_h += h
   135→   135→   152→   152→   552→   552→   552→    if total_h <= MAX_KEEP_HEIGHT:
   136→   136→   153→   153→   553→   553→   553→        return [KeepTogether(elements)]
   137→   137→   154→   154→   554→   554→   554→    elif len(elements) >= 2:
   138→   138→   155→   155→   555→   555→   555→        # Keep at least title + first element together to prevent title orphaning
   139→   139→   156→   156→   556→   556→   556→        return [KeepTogether(elements[:2])] + list(elements[2:])
   140→   140→   157→   157→   557→   557→   557→    else:
   141→   141→   158→   158→   558→   558→   558→        return list(elements)
   142→   142→   159→   159→   559→   559→   559→
   143→   143→   160→   160→   560→   560→   560→# Heading stays with first paragraph
   144→   144→   161→   161→   561→   561→   561→story.extend(safe_keep_together([
   145→   145→   162→   162→   562→   562→   562→    heading_paragraph,
   146→   146→   163→   163→   563→   563→   563→    first_body_paragraph,
   147→   147→   164→   164→   564→   564→   564→]))
   148→   148→   165→   165→   565→   565→   565→
   149→   149→   166→   166→   566→   566→   566→# Image + caption: keep together ONLY if image is small
   150→   150→   167→   167→   567→   567→   567→story.extend(safe_keep_together([image, caption_paragraph]))
   151→   151→   168→   168→   568→   568→   568→
   152→   152→   169→   169→   569→   569→   569→# Table title + table: keep together ONLY if table is short
   153→   153→   170→   170→   570→   570→   570→if len(table_data) <= 15:
   154→   154→   171→   171→   571→   571→   571→    story.extend(safe_keep_together([table_title, table]))
   155→   155→   172→   172→   572→   572→   572→else:
   156→   156→   173→   173→   573→   573→   573→    # Long table: just keep title with the table start
   157→   157→   174→   174→   574→   574→   574→    story.extend(safe_keep_together([table_title]))
   158→   158→   175→   175→   575→   575→   575→    story.append(table)
   159→   159→   176→   176→   576→   576→   576→```

   161→   161→   178→   178→   578→   578→   578→**⚠️ KEY INSIGHT:** `KeepTogether` is the #1 cause of “empty page with chart on next page”.
   162→   162→   179→   179→   579→   579→   579→When a `KeepTogether` block is taller than the remaining space on the current page,
   163→   163→   180→   180→   580→   580→   580→ReportLab pushes the **entire block** to the next page, leaving the current page mostly empty.

   255→   255→   272→   272→   672→   672→   672→    """Render HTML cover to PDF via html2poster.js.

   257→   257→   274→   274→   674→   674→   674→    ⚠️ ALWAYS use html2poster.js for covers (NOT html2pdf-next.js).
