    53→## Common Error Codes
    54→
    55→| Code | Meaning |
    56→|------|---------|
    57→| `400` | Bad Request — missing or invalid fields |
    58→| `401` | Unauthorized — invalid API key or session |
    59→| `403` | Forbidden — internal domain, insufficient permissions, or cross-org access denied |
    60→| `404` | Not Found — resource does not exist |
    61→| `409` | Conflict — duplicate resource or already revoked |
    62→| `429` | Too Many Requests — rate limit exceeded |
    63→| `500` | Internal Server Error |

    67→## 1. Authentication
    68→
    69→### POST `/api/auth/login`
    70→
    71→Authenticate with email/password and receive a session token + API key.
    72→
    73→- **Auth Required:** No (public endpoint)
    74→- **Rate Limit:** 10 requests / 60s
    75→- **Request Body:**
    76→
    77→| Field | Type | Required | Description |
    78→|-------|------|----------|-------------|
    79→| `email` | `string` | Yes | User email |
    80→| `password` | `string` | Yes | User password (min 1 char) |
    81→
    82→- **Response (200):**
    83→```json
    84→{
    85→  "success": true,
    86→  "member": { "id": "cm...", "name": "Alex Chen", "email": "alex@acme.com", "role": "owner" },
    87→  "org_id": "org_...",
    88→  "api_key": "rp_live_..."
    89→}
    90→```
    91→- Sets `reconpro_session` HttpOnly cookie (24h expiry).
    92→
    93→### POST `/api/auth/register`
    94→
    95→Create a new account, organization, and API key in one step.
    96→
    97→- **Auth Required:** No (public endpoint)
    98→- **Rate Limit:** 5 requests / 60s
    99→- **Request Body:**
   100→
   101→| Field | Type | Required | Description |
   102→|-------|------|----------|-------------|
   103→| `name` | `string` | Yes | Display name |
   104→| `email` | `string` | Yes | Valid email address |
   105→| `password` | `string` | Yes | Min 8 characters |
   106→
   107→- **Response (201):**
   108→```json
   109→{
   110→  "success": true,
   111→  "member": { "id": "cm...", "name": "Alex Chen", "email": "alex@acme.com", "role": "owner" },
   112→  "api_key": "rp_live_...",
   113→  "org_id": "org_..."
   114→}
   115→```
   116→- **Notes:** API key is shown only once. Organization slug is auto-derived from email domain.
   117→
   118→### POST `/api/auth/forgot-password`
   119→
   120→Request password reset instructions.
   121→
   122→- **Auth Required:** No (public endpoint)
   123→- **Rate Limit:** 5 requests / 60s
   124→- **Request Body:**
   125→
   126→| Field | Type | Required | Description |
   127→|-------|------|----------|-------------|
   128→| `email` | `string` | Yes | Account email |
   129→
   130→- **Response (200):**
   131→```json
   132→{ "success": true, "message": "If an account exists with this email, password reset instructions will be sent." }
   133→```
   134→- **Notes:** Always returns success to prevent email enumeration. Actual reset functionality is not yet implemented.
   135→
   136→### POST `/api/v1/auth/validate`
   137→
   138→Validate an API key and return metadata.
   139→
   140→- **Auth Required:** No (key passed in body)
   141→- **Rate Limit:** 30 requests / 60s
   142→- **Request Body:**
   143→
   144→| Field | Type | Required | Description |
   145→|-------|------|----------|-------------|
   146→| `api_key` | `string` | Yes | Raw API key to validate |
   147→
   148→- **Response (200):**
   149→```json
   150→{
   151→  "valid": true,
   152→  "org_id": "org_...",
   153→  "quota_remaining": 1000,
   154→  "scopes": ["scan:read", "scan:write", "telemetry:write"],
   155→  "key_name": "Default key",
   156→  "key_prefix": "rp_live_a1b2",
   157→  "created_at": "2025-01-01T00:00:00.000Z"
   158→}
   159→```

   202→## 3. Core Scanning
   203→
   204→### POST `/api/scan`
   205→
   206→Full reconnaissance scan against a target domain. Runs DNS, SSL/TLS, port, HTTP, subdomain, WHOIS, email, cert, and geo analysis modules.
   207→
   208→- **Auth Required:** Yes (`x-api-key` header)
   209→- **Rate Limit:** 5 requests / 60s
   210→- **Request Body:**
   211→
   212→| Field | Type | Required | Description |
   213→|-------|------|----------|-------------|
   214→| `domain` | `string` | Yes | Target domain (FQDN) |
   215→| `scanType` | `string` | No | `"full"` (default) or `"quick"` |
   216→| `triggeredBy` | `string` | No | `"manual"`, `"scheduled"`, or `"api"` |
   217→
   218→- **Response (200):**
   219→```json
   220→{
   221→  "success": true,
   222→  "domain": "example.com",
   223→  "scanId": "scan_...",
   224→  "status": "completed",
   225→  "riskScore": 42,
   226→  "findings": [
   227→    { "title": "SPF Record Missing", "severity": "high", "category": "dns", "description": "...", "evidence": null, "asset": "example.com" }
   228→  ],
   229→  "summary": { "total": 15, "critical": 1, "high": 3, "medium": 5, "low": 4, "info": 2 }
   230→}
   231→```
   232→- **Error Codes:** 400 (invalid domain, missing field), 403 (internal/blocked domain, private IP resolution), 401, 429, 500.
   233→
   234→### GET `/api/scan/stream`
   235→
   236→Server-Sent Events (SSE) real-time scan stream.
   237→
   238→- **Auth Required:** Yes
   239→- **Rate Limit:** 10 requests / 60s
   240→- **Query Params:**
   241→
   242→| Param | Type | Required | Description |
   243→|-------|------|----------|-------------|
   244→| `domain` | `string` | Yes | Target domain |
   245→
   246→- **Response:** `Content-Type: text/event-stream`
   247→  - Events: `phase_start`, `phase_complete`, `phase_error`, `finding`, `scan_complete`, `scan_error`
   248→- **Phases:** DNS Reconnaissance → SSL/TLS Analysis → Port Scanning → HTTP Header Analysis
   249→
   250→### POST `/api/vuln-scan`
   251→
   252→Targeted vulnerability scan with native Node.js port probing, TLS analysis, and CVE matching.
   253→
   254→- **Auth Required:** Yes
   255→- **Rate Limit:** 5 requests / 60s
   256→- **Request Body:**
   257→
   258→| Field | Type | Required | Description |
   259→|-------|------|----------|-------------|
   260→| `domain` | `string` | Yes | Target domain |
   261→
   262→- **Response (200):** Similar to `/api/scan` with detailed findings including CVE and CVSS data.
